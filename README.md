# USA-PON TOOLS

LINE Creators Marketへ提出する静止画スタンプを、ブラウザ上で仕上げるためのツールです。

- 複数画像をドラッグ＆ドロップ
- 370 × 320pxの透明PNGへ自動配置
- 余白、白背景除去、白フチを一括調整
- 8 / 16 / 24 / 32 / 40枚のセット数チェック
- `main.png`（240 × 240px）と`tab.png`（96 × 74px）を自動生成
- 申請用ファイルをZIPで一括ダウンロード
- 画像処理はすべてブラウザ内で完結（サーバーへの画像送信なし）

## 開発を始める

Node.js 20以降を用意し、次のコマンドを実行します。

```bash
npm install
npm run dev
```

表示されたURL（通常は `http://localhost:5173`）をブラウザで開いてください。

## 確認コマンド

```bash
npm test
npm run build
```

## 対応しているLINE画像仕様

| 種類 | 出力サイズ | ファイル名 |
| --- | --- | --- |
| スタンプ画像 | 370 × 320px | `01.png` 〜 `40.png` |
| メイン画像 | 240 × 240px | `main.png` |
| トークルームタブ画像 | 96 × 74px | `tab.png` |

スタンプ画像は1枚1MB以下、PNG、RGB、背景透過を前提に検査します。最新の条件は[LINE Creators Market 制作ガイドライン](https://creator.line.me/ja/guideline/)も確認してください。

## 現在の対象

この初期版は通常の静止画スタンプ向けです。アニメーションスタンプ（APNG）、BIGスタンプ、ポップアップスタンプには未対応です。
